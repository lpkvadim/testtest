# Замер выбора видео на айфоне

Одна страница, чтобы понять, почему «Фотоплёнка» долго думает над видео перед
загрузкой в кабинете эксперта. Четыре кнопки просят у телефона файл
по-разному — так, как просит кабинет сегодня, и тремя другими способами, — и
мерят два числа: сколько плёнка думала после «Добавить» и сколько заняло
чтение байтов.

Открывать на том айфоне, где тормозит, и прогонять все четыре кнопки на одних
и тех же видео. Имя и формат, под которыми файл пришёл, говорят главное:
`.mov` — телефон отдал оригинал, `.mp4` — пересобрал, и минуты ушли на это.

Видео никуда не отправляется: страница читает файл у себя в телефоне и считает
секунды. Ни одного запроса наружу, кроме загрузки самой страницы.
